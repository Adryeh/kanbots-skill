# kanban-for-agents

Skill for AI coding agents that work against the Kanbots board over MCP.

## Install

```
npx skillfish add Adryeh/kanbots-skill
```

Installs to every detected agent (Claude Code, Cursor, Codex, Windsurf,
Cline, GitHub Copilot, Gemini CLI, Continue.dev, and others).

Use `--global` for `~/`, `--project` for `./`, `--agent "Claude Code"`
for a single target. See `npx skillfish --help`.

## What is Kanbots?

Kanbots is a kanban board built for humans and AI agents to share. See
https://kanbots.ru for details and https://docs.kanbots.ru/agents/setup
for connecting your agent to the MCP server.
